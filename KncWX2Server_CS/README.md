# KncWX2Server (.NET 11 / C#)

Modern C# (.NET 11) single-binary multi-region (`TW` / `HK` / `CN` / `JP`) port of the full `KncWX2Server` suite, featuring MoonSharp Lua scripting, self-contained SQLite persistence, wire-compatible TCP/UDP encryption & relaying, and a unified WPF Host GUI.

## Architecture

- **`src/KncWX2Server.Core`** (`net11.0`)
  - **`Region/`**: `RegionCode` (`TW`, `HK`, `CN`, `JP`), `RegionProfile` (runtime feature flags, port profiles, & regional protocol toggles verified across `TW`/`HK`/`CN`/`JP`), `KncUid` (40-bit vs `CN` 36-bit/10-bit ServerGroupID bitpacking), `NetError` / `NetErrorRegistry`.
  - **`Serialization/`**: Wire-compatible `KSerializer` (Big-Endian numerics, UTF-16LE `wstring`, 1-byte `bool`, `m_tagsEnabled = false`) and `KSerBuffer` (zlib level-1 compression with 4-byte Little-Endian origin size header).
  - **`Security/`**: Wire-compatible `KSecurityAssociation`, `KSADatabase`, and `KSecureBuffer` (`SPI` + `SeqNum` + 8-byte IV + `DES-CBC` RFC 2406 padding + 10-byte truncated `HMAC-MD5` ICV; default `SPI=0` keys + per-session SPI handshake).
  - **`Events/` & `Packets/`**: All **3,415** compiler-verified C++ EventIDs (`0..3385` + `60001..60027`), `KEvent`, `PerformerId`, `CommonPackets`, `SystemPackets`, `ClientPackets`, `ServerPackets`, `GameplayCommonPackets`, and `GameClientPackets` (including PvP/Dungeon end-game results, Second Security PIN, Party Dungeon/Ready/Start/Legacy Party ops, Guild operations, Enchant/Socket/Resolve/Attrib, Player Trade, Pets/RidingPets/Intimacy items, Skill Pages & Skill Note Memos, Local Rankings, Events/Attendance/Jumping/Coupon, TW Global Billing/CashShop/Bingo/Coupons, and full GM Admin commands).
  - **`Network/`**:
    - `KIocpServer` & `KTcpSession` (2-byte LE framing, `E_ACCEPT_CONNECTION_NOT` SPI handshake, `E_HEART_BEAT`, `E_RESERVE_DESTROY`)
    - `KUdpRelayServer` (port of `CKTDNUDP`: `SP_CONNECT_RELAY_REQ/ACK`, `SP_RELAY_SET_UID_LIST_REQ/ACK`, `SP_RELAY_PRECONFIG`, `SP_RELAY`, `SP_HEART_BEAT_*`, forwarding `XPT_*` P2P payloads transparently)
    - `KUdpEchoServer` (port of `KUdpEcho`: 10-byte `KUdpToServer` -> `E_UDP_PORT_NOT`)
  - **`Framework/`**: `KCHFSM`, `KRepeatEventFilter`, `KPerformer`, `KActor`, `KActorManager`, `InProcessRouter`, `KBaseServer`, `KSimLayer`, `KNetLayer`, `KSectorId` (32-bit packed 3D spatial sector partitioning, sorted 3x3x3 adjacency, and `FindRemainder` sector-delta calculation), `KLottery` (weighted probability roulette), `KExpTable`, `KClassChangeTable`, `KStringFilterManager`, `KPunishmentManager`, `KStatisticsManager`, `KGameSysValTable`, `KRewardTable`, `KSpiritTable`, and `KBuffManager`.
  - **`Scripting/`**: **MoonSharp** (`KScriptManager`) executing original `config_*.lua`, `WaitQueueData.lua`, `GameSysValTable.lua`, and `SMSPhoneNumberList.lua`.
  - **`Database/`**: Self-implemented **SQLite** persistence (`SqliteDatabaseManager`, `KDBLayer`, `KDBThread`) covering 51 tables (Accounts with HackingUserType/ChannelingCode, ServerGroups/ServerList/Channels, Units with Elo Rating/RPoint/KFactor/Spirit/TitleID/SPoint/CSPointEndDate/ServerGroupID/RestoreAbleDate/SkillPageCount/ActiveSkillPage/SkillNotePages/WarpVipEndDate, InventoryItems with EnchantLevel/IsBroken/SocketIds/AttribEnchant/EvalState, UnitSkillSlots, UnitTitles, UnitPets, UnitRidingPets, UnitRecruiters, BillingOrders, CashWishLists, CashCoupons, CheatLogs, UserSettings, UserLocalRankingProfiles, UserEventProgress, UserRecommendations, HackAndPortLogs, MailLetters, PostBlackList, LoveLetters, Guilds with GuildSPoint/GuildMembers/GuildSkillTree/GuildApplies/GuildAds, Quests, SecondSecurity, AccountBlockEntries, PersonalShopListings/Agency, Friendships/FriendGroups, BlackListUsers, Weddings, UnitRelationships, UserSystemInfos, GamePerformanceLogs, UserHackingProcessLogs, FieldWorkingsBlockLogs, GamePlayNetworkLogs, Logs, and SMS) with automatic seeding for `TW`, `HK`, `CN`, and `JP`, `KExpTable`-driven leveling, and atomic player-trade transactions.

```powershell
cd KncWX2Server_CS
dotnet restore
dotnet build KncWX2Server.sln
dotnet test tests/KncWX2Server.Tests/KncWX2Server.Tests.csproj
dotnet run --project src/KncWX2Server.Host/KncWX2Server.Host.csproj
```

### ServerResource diagnostics

The WPF host selects `TW` by default and loads Login plus Game resources at startup;
the Game loader also loads Center and Global resources, while Channel loads its
own resources on start. `Lua Config` is a Channel configuration **file**, not
the ServerResource directory. Resource discovery checks the working directory
and executable directory and their ancestors for `KncWX2Server/ServerResource`
or `ServerResource`. Within a root, the regional file is preferred to the common
file. A programmatic `resourceBaseDir` is searched first, but missing files can
still fall back to automatically discovered roots.

At log level 2, `[ServerResource] Executed:` records the actual path. Missing
files are warnings and may be optional; Lua errors are reported separately.
The Game/Center/Global counts report successful script execution, not complete
feature compatibility or a guarantee that every table was applied. Resource
loaders use explicit file lists and bindings, not every file in the directory.
Some results are implemented in C# rather than evaluated from Lua functions.
